# wordfreq

`wordfreq` は、テキストファイルの単語の出現回数を数え、多い順に表示するコマンドです。
ログや文章で、どの語が多く使われているかを手早く調べたい人に向けています。

## 特徴

- 単語を回数の多い順に表示する。回数が同じ単語は文字コードの順に並べるので、実行のたびに同じ並びになる
- `--top N` で、表示する単語の数を変えられる。既定は 10 である
- ファイルの行数を、1行目に表示する
- Rust の標準ライブラリだけで書いている。外部のクレートは使っていない

## 動作環境

Rust 1.95.0 と Windows 11 で動くことを確かめています。ほかの OS では確かめていません。

## インストール

リリースした実行ファイルはありません。ソースコードからビルドします。
このリポジトリを clone し、`samples/wordfreq` フォルダで次のコマンドを実行します。

```bash
cargo build --release
```

実行ファイルは `target/release` フォルダにできます。

## 使い方

同じフォルダで、付属の `sample.txt` を数えます。

```bash
cargo run -q --release -- sample.txt --top 3
```

行数と、回数の多い3語が表示されます。

```text
lines: 3
     3 the
     1 brown
     1 dog
```

## 開発段階と、まだ使えない機能

バージョンは 0.1.0 で、リリースはまだありません。次の3つは、いまの版ではできません。

- 存在しないファイルを渡すと、panic して終了コード 101 で終わる（[不具合の報告](../issue-bug.md)）
- 標準入力からは読めない（[機能の要望](../issue-feature.md)）
- 大文字と小文字、句読点をそろえずに数える。`End` と `end.` は別の単語になる
