# 日本語のルール

出力言語が日本語のときに、共通ルール（`rules/common.md`）に加えて適用する規則です。
日本語の文体・語順・語彙・表記と、共通ルールを日本語で具体化する基準を書いています。
共通ルールと同じ内容は、ここには書いていません。

各節の冒頭に狙いを書いています。列挙にない場面に出会ったら、狙いに照らして判断してください。
規則の文面より狙いを優先します。

## 文体

狙いは、読み手が文体から場面を判断できるようにすることです。
文書は、書いた人がいない場所で他人が読みます。

語り口と文末は別の軸として扱います。出力先ごとに次の組み合わせを使ってください。

| 出力先 | 語り口 | 文末 |
| :-- | :-- | :-- |
| 説明するために書く文章(README、設計メモ、仕様、手順書、PR) | 書き言葉 | 地の文は敬体、箇条書きは常体、規則は「～こと」 |
| SKILL | 書き言葉 | 地の文は敬体、箇条書きは常体、規則は「～こと」 |
| コミットメッセージ | 書き言葉 | 常体、体言止めでよい |
| コード内のコメント | 書き言葉 | 常体、短く |
| UI 文言、ユーザー向けのエラーメッセージ | 既存の慣行に合わせる | 同左 |

UI 文言のみ慣行に従うのは、同じリポジトリの中で文体が揺れるのを防ぐためです。

### 書き言葉
- 文頭の「でも」「なので」を使わないこと。「ただし」「そのため」とする。
- 縮約しないこと。「〜てる」ではなく「〜ている」。
- 「〜みたいな」「〜とか」「ちょっと」「けっこう」を使わないこと。
  程度が読み手に伝わらず、後から読む人が判断できない。

### 文末と主語
- 地の文の敬体と常体を混ぜないこと。
- 「〜だ」を使わないこと。常体は「〜する」「〜しない」「〜である」の終止形を使う。
- 受け入れ条件は「～こと」を使った終止形を使う。
- 同じ語尾や同じ主語が3文続いたら、文をまとめるか語順を変えること。
  「です。」の羅列は機械的な印象を与え、読者を疲弊させる。
- 一人称・二人称を書かないこと。日本語は主語を省くのが一般的で、
  書くと英語からの直訳に見える。省略すると意味が変わる場合だけ書く。
  自分の作業も「私は修正しました」ではなく「修正しました」とする。
- 無生物主語を使わないこと。英語の SVO をそのまま写した形になる。

  避ける: この設定は起動時間を短縮します
  書く:   この設定で起動が速くなります

- 「〜を可能にします」「〜を提供します」「〜を意味します」「〜を示しています」を使わないこと。
  いずれも英語の動詞をそのまま訳した形である。
- 過剰な謙譲を避けること。「〜させていただきます」ではなく「〜します」とする。二重敬語を使わない。

## 語順と文の長さ

狙いは、1文を1回で読み取れる長さに保つことです。長い文は、読点の位置で係り受けが分かれ、
読み手ごとに解釈が変わります。
共通ルールの「一文一意」を、日本語では次の基準で確かめます。

- 日本語として自然な語順(SOV)を基本とすること。
- 1文は60字程度とすること。
- 読点が3つ以上ある文は長すぎるサインなので、割れないか検討すること。
- 連体修飾節の入れ子は1段までとすること。2段になったら文を割る。
  日本語は修飾が前に来るので、入れ子が深いと述語まで意味が確定しない。

## 否定の言い換え

共通ルールの「肯定形と否定形」を、日本語では次の形で確かめます。

- 否定辞のない二重否定も、二重否定と同じ扱いとすること。「〜を避けられない」「〜せざるを得ない」
  「〜なしには〜できない」は、肯定形で言い換える。
- 否定条件を肯定条件に読み替えること。「〜がないと」は「〜があれば」、
  「〜しない限り」は「〜したときに」とする。

## 語彙と表記

狙いは、日本語として組み立てた文にすることです。英語の抽象名詞や前置詞句を漢語に
一対一で写すと、意味は通っても読む速度が落ちます。

- 英語のイディオム由来の表現は禁止します。和語での言い換えを検討しましょう。
  - 経路、正典、聖典は禁止です
- 和語で言えるところは和語にすること。実施する→行う、使用する→使う、差異→違い。
- ひらいても差し支えない漢字はひらくこと。
- 次の言い換えを適用すること。

  〜することが可能です  → 〜できます
  〜という事実          → 〜こと、または文を組み替える
  〜に関して / における  → 〜の、〜で、〜について
  〜の観点から          → 〜として見ると
  〜を行う / を実施する  → 〜する
  〜する必要があります   → 〜してください、〜が要ります

- 次の語句を使わないこと。いずれも英語の定型句を訳した形で、内容を足していない。

  しかしながら / 注目に値します / 〜と言えるでしょう / 重要なのは〜という点です
  〜することをお勧めします(「〜するといいです」「〜してみてください」とする)
  〜かもしれません(何がどう不確実なのかを具体的に書く)

## 校正で確かめる項目

共通ルールの「校正で確かめる項目」に加えて確かめます。

| 項目 | 直し方 |
| :-- | :-- |
| 重言 | 「まず最初に」「今現在」「不快感を感じる」のような意味の重なりを削る |
| 順接の接続詞の多用 | 「よって」「だから」「そのため」が続いたら、文を短く切って接続詞を削る |
| カタカナ語・慣用句 | 読み手が知らない可能性のある語は、平易な語に直すか初出で説明する |
